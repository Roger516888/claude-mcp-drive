隱私權政策

適用於 Claude MCP Drive（個人自用工具）｜回首頁

一、使用對象

本工具只供專案擁有者本人使用，不對外提供服務，不蒐集其他人的資料。

二、存取哪些資料

  • 擁有者本人授權的 Google 雲端硬碟檔案內容與檔案資訊（檔名、資料夾位置、大小、修改時間、MD5 校驗值）。
  • 用途僅限：上傳擁有者電腦上的工作檔案備份、比對雲端與本機檔案是否一致、在擁有者自己的雲端硬碟內搬移與整理資料夾。

三、資料存放與分享

  • Google 授權權杖只存放在擁有者自己的電腦上。
  • 不將任何資料傳送、出售或提供給第三方，不用於廣告，也不做行為分析。
  • 檔案只在擁有者的電腦與擁有者的 Google 雲端硬碟之間傳輸。

四、遵守 Google API 規範

本工具使用及傳輸從 Google API 取得的資訊時，遵守 Google API Services User Data Policy，包括其中的 Limited Use 規定。

五、撤銷授權

可隨時到 https://myaccount.google.com/permissions 移除本工具的存取權限，移除後本工具即無法再存取雲端硬碟。

六、聯絡方式

如有疑問，請透過本頁所在的 GitHub 專案頁面聯絡擁有者。

English summary

Claude MCP Drive is used only by its owner. It accesses only the owner's own Google Drive files and file metadata, solely to back up, verify and organize the owner's files. OAuth tokens are stored only on the owner's computer. No data is shared with, sold to, or transferred to any third party, and no data is used for advertising or analytics. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
