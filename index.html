Claude MCP Drive

個人自用的 Google 雲端硬碟備份與整理工具

這是什麼

Claude MCP Drive 是本專案擁有者自己使用的小工具。它讓擁有者電腦上的備份與整理程式，透過 Google Drive API 存取擁有者本人的 Google 雲端硬碟，用來上傳工作檔案備份、比對檔案是否完整，以及整理資料夾。

本工具不對外提供服務，也不開放其他人登入使用。

隱私權政策

本工具如何使用與保護資料，請見 隱私權政策。

English summary

Claude MCP Drive is a personal, single-user tool. It lets the owner's own local scripts back up and organize files in the owner's own Google Drive through the Google Drive API. It is not offered to the public. See the Privacy Policy.
